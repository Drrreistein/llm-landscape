# 大语言模型产业研究

以供应链图谱为入口，把这条产业链拆成 **25 个环节、138 家企业**，并附上行业观察笔记与相关公司研报。

**在线访问**：https://drrreistein.github.io/llm-landscape/

---

## 首页有什么

首页顶部附一篇 [《大语言模型行业观察笔记》](reports/大语言模型行业观察笔记.html)——个人整理的行业笔记，不是正式研报，数据来自公开信息，仅供参考。

首页是一张可交互的产业链图谱，提供四个视角：

| 视角 | 回答的问题 |
| :--- | :--- |
| 供应链图谱 | 上游器件、中游产品、下游场景、支撑层，各自有哪些玩家？ |
| 第二视图 | 按本行业的核心分层维度切分 |
| 按应用场景 | 各家企业在哪些场景落地？ |
| 按玩家模式 | 玩家模式 × 核心维度 的企业矩阵 |

点击带绿点的公司名，直达调研报告；灰色表示暂无报告。

## 目录结构

```
.
├── index.html              # 首页：产业链图谱（自包含，无外部依赖）
├── reports/
│   ├── *.html              # 渲染后的报告页面（5 份）
│   └── md/                 # 报告 Markdown 原稿
├── tools/
│   ├── build_sites.py      # 首页生成脚本（三个站点共用，见主工作区）
│   └── build_reports.py    # 公司研报 Markdown → HTML
└── .gitignore
```

## 维护

- 主报告以 Markdown 为源，用 `md2simple.py`（主工作区 `tools/`）渲染成极简单栏 HTML。
- 公司研报用 `python tools/build_reports.py` 批量渲染；脚本会跳过 `*行业观察笔记.md`，避免覆盖主报告。
- 首页数据数组位于 `index.html` 底部 `<script>` 中，格式为：
  `["公司名", ["环节代码"], ["维度代码"], ["场景代码"], "报告文件名或 null", "玩家模式"]`
