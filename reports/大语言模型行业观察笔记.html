大语言模型行业观察笔记

个人整理的行业笔记，不是正式研报。数据来自公开信息和各机构报告，这个行业的口径特别乱，同一件事经常能查出三个不同的数字，看法难免有偏差，仅供参考。数据截至 2026 年 10 月。

一、先说结论

2026 年的大模型行业，有点像 2000 年前后的互联网：用户和收入都在高速增长，但没人说得清最后谁赚钱。我自己的判断，大致是这几条：

1. "谁第一"这件事，完全取决于你问谁、用什么口径。 按 Counterpoint 的 2026 年一季度收入份额，Anthropic 31.4%、OpenAI 29.0%；按 Menlo 的企业 LLM 支出调查，Anthropic 40%、OpenAI 27%；但另一份按 API 收入的估算又说 OpenAI 占 55%。三个结论都有人背书，差别在"算不算 C 端订阅""算不算云捆绑""算不算关联交易"。所以看到"某家份额第一"的标题，先问口径。

2. 收入在涨，单价在崩。 2026 年 8 月出现了一个标志性变化：token 调用量继续涨，但美元收入增速明显放缓。高盛的说法是，过去两年"更多 token 等于更多收入"的假设第一次被打破。原因有三个：供给端打价格战、企业开始做成本治理、大企业自建推理集群把流量从公有 API 剥离（这部分只耗算力，不产生 API 收入）。

3. 护城河正在从"模型能力"转向"分发、上下文和记忆"。 当模型能力差距缩小、价格快速趋同，决定胜负的就不再是榜单分数，而是你有没有入口（Office、搜索、社交、手机）、有没有用户的长期上下文、能不能嵌进企业流程。

4. 资本开支是这轮最大的风险敞口。 前五大 AI 公司 2026 年的 AI 基建支出合计超过 3,000 亿美元；Anthropic 在招股书里披露，已承诺未来在云服务和算力上支出 5,180 亿美元。这些钱能不能靠推理收入收回来，目前还没有被验证。

5. 企业用起来了，但回报没跟上。 德勤中国和港大的调查显示，2026 年进入生产部署的企业占比从 56.0% 升到 64.4%，但同时有 48.5% 的企业说 AI 项目实际回报低于预期，44.4% 根本算不清 ROI。这个落差，是 2026 年底到 2027 年续约季最大的变数。

6. 这一轮最确定的受益者可能是应用层，最不确定的是基础模型层。 模型越便宜，应用越容易赚钱；但模型厂商自己在打价格战、扛资本开支。这个结构有点像当年的云计算：卖算力的赚辛苦钱，用算力的做出高毛利生意。

支撑上面几条的事实：

  • 规模：2026 年一季度全球大模型月活用户超过 38 亿，单季收入约 207 亿美元，折年约 830 亿美元。
  • 集中度：收入端前四家（Anthropic、OpenAI、Google、Microsoft）合计约 80%。但用户端是另一幅图景：Meta 10 亿月活、OpenAI 9 亿、Google 7.5 亿，而 Anthropic 只有 6,500 万。
  • 单用户价值差异极大：Anthropic 月均每用户收入 33.3 美元，Microsoft 5.0，OpenAI 2.2，Google 1.1，Meta 和字节只有 0.1 甚至接近 0。做"全民平台"和做"高端专业市场"，是两种完全不同的生意。
  • 编程是第一个跑通的场景：Claude Code 的使用率从 2025 年初的 3% 涨到 2026 年中的 39%；90% 的职业开发者每周至少用一次 AI 编程代理，68% 每天用。
  • 价格：2024 年初 GPT-4 级别的价格大约是每千输入 token 0.03 美元，2026 年已经降到 0.01 美元以下；DeepSeek V4 Flash 的定价是每百万 token 0.098/0.197 美元，和 2024 年的 Claude Sonnet（3/15 美元）比，差了大约 30 倍。

我相对关注和回避的方向

下面只是个人研究记录，不构成任何投资建议。

方向 代表 大致逻辑 我担心的点

二、规模数字，先看清口径

这个行业最容易被误导的地方，是同一件事有太多"正确"的数字。

同一个"份额"，三个答案

来源 口径 结论
Counterpoint（2026 Q1） 全球大模型厂商收入份额 Anthropic 31.4%，OpenAI 29.0%，Google 12.1%，Microsoft 7.2%
Menlo Ventures（2025 年 12 月） 企业 LLM 支出份额 Anthropic 40%，OpenAI 27%，Google 21%
某独立估算（2026 年 5 月） API 收入份额 OpenAI 约 55%，Anthropic 约 20%，Google API 约 12%

三份数据不矛盾，只是问的问题不同：第一份算的是"所有收入"，第二份只算"企业支出"，第三份只算"API"。如果一家公司 C 端订阅很强、企业端一般，它在第一份里高、第二份里低；反过来也一样。

ARR 和收入，也不是一回事

  • 有报道引用 The Information 的数据，说 OpenAI 2026 年初的年化收入（ARR）超过 34 亿美元。
  • 但 SemiAnalysis 2026 年 6 月的测算是，Anthropic 和 OpenAI 的 ARR 分别约 620 亿美元和 435 亿美元。
  • Anthropic 自己提交的 S-1 显示，2026 年上半年实际营收 162.86 亿美元。

34 亿和 435 亿差了十倍以上。原因可能是统计范围（只算 API？还是含 C 端订阅？）、时间点、以及"年化"的算法（最近一个月乘 12，还是最近一季度乘 4）。这不是谁造假，是口径没统一。所以看到 ARR，最好同时看"实际确认收入"。

这张表比份额表更有信息量：Anthropic 用 6,500 万用户做出了 31.4% 的收入，OpenAI 用 9 亿用户做出 29.0%。一个是"少而贵"，一个是"多而便宜"。哪种更可持续，取决于企业付费能不能守住。

市场规模

2026 年一季度全球大模型收入约 207 亿美元，年化约 830 亿美元。这个数只算"模型层收入"（订阅+API），不含云资源、不含应用层收入、不含芯片。如果把这些都算进去，"AI 产业"是万亿级；但那是另一个口径。

讨论"市场多大"时，我一般会先问三句：算不算应用？算不算云？算不算硬件？三个都算，数字能差十倍。

三、行业现在大概是什么样

分四层看

  • 基础模型层：前沿闭源（OpenAI、Anthropic、Google、xAI）、开源权重（Meta Llama、DeepSeek、Qwen、Kimi、MiniMax、智谱）、垂直模型（法律、医疗、金融）。
  • 云与算力层：英伟达、AMD、自研 ASIC（TPU、Trainium）、云厂商、数据中心和电力。
  • 中间层：推理服务、模型路由、向量数据库、Agent 框架、评测与安全。
  • 应用层：编程（Cursor、Claude Code、Copilot）、客服、知识库、垂直 SaaS、消费级应用。

利润分布很不均匀：算力层赚确定的钱但周期性强，模型层收入高但亏损大，应用层毛利高但容易同质化。

能力阶段，最好分四档

榜单分数对决策帮助不大，我一般按"能不能托管"来分：

  • 演示可用：能跑通 demo，换个输入就不稳定。
  • 辅助可用：人能兜底，比如写代码补全、写初稿。现在大部分编程工具在这一档。
  • 流程可用：能嵌进固定流程，出错率可控，比如客服工单分类、合同要素抽取。
  • 可托管：端到端负责，人不用盯，出错有兜底机制。现在很少。

大部分企业项目停在第二、三档，但采购时的预期是按第四档谈的。这是 ROI 落差的主要来源。

需求真实性

知识库/RAG 中 项目多，但很多停在试点

一个可参考的数字：Anthropic 只有 7.3% 的用户订了 100 美元以上的套餐，但这部分贡献了很大比例的收入。说明"愿意为生产力付高价"的人是小众，但这小众很值钱。

一年半前，这些低价档的价格是不可想象的；一年半后，它们大概也会显得贵。对应用层是好事，对模型层是压力。

算力：这轮真正的硬约束

2026 年出现了一个结构性变化，叫"推理翻转"：推理第一次超过训练，占到 AI 基础设施支出的 55%–70%。这意味着算力需求从"阶段性投入"变成了"持续性开支"。

价格上，Blackwell 相比 Hopper 把每 token 成本降了约 3 倍，GB200 NVL72 整机方案据说能到 10 倍。但需求涨得更快，所以总支出还是在涨。

一个容易被忽略的浪费：多项调研显示，企业 GPU 云支出的 35%–60% 花在了过度配置、闲置和错配的实例上。这不是技术问题，是运维问题。

四、产业链的钱落在哪

成本结构

一个前沿模型的成本，大致分三块：

成本项 占比（大致） 说明
算力（训练+推理） 60%–75% 训练一次性、推理持续性；现在推理占比在上升
人才 15%–25% 研究员薪酬极高，且流动性大
数据与标注 5%–15% 高质量数据越来越贵，合成数据补位

Anthropic 的 S-1 给了个少见的参照：2026 年上半年营收 162.86 亿美元，算力和基础设施支出近 90 亿美元，简单算下来，算力成本约占收入的一半多。这个比例说明，即便是收入增长最快的公司，也还在"用算力换收入"的阶段。

各层的毛利

层 毛利大致水平 说明
芯片 60%–75% 英伟达最强，ASIC 略低但自有云更省
云 25%–40% 重资产，规模效应明显
基础模型 API 20%–50%（波动大） 价格战下被压，前沿推理稍好
模型订阅 60%–80% 边际成本低，但要养免费用户
应用/Agent 50%–75% 模型成本下降直接改善毛利
垂直 SaaS 70%–85% 客户为流程付费，不按 token

一个反直觉的点：基础模型公司的毛利，可能比应用公司低。 因为它要同时承担训练、推理和价格战，而应用公司只承担推理成本，还能挑最便宜的模型。

五、技术上的几个观察

预训练的边际在递减，后训练在崛起

2023–2024 年，大家比的是参数量、数据量、训练算力，scaling law 很管用。到 2026 年，单纯堆预训练的收益明显变小：数据快用完了，算力成本又高，榜单提升越来越难。

增量主要来自后训练：强化学习、合成数据、推理链、工具调用。推理模型（test-time compute）是这两年的主线——让模型在回答前多想一会儿，用推理算力换质量。这条路线的好处是"能力可以按需付费"，坏处是推理成本上升，和降价趋势矛盾。

MoE 和效率

混合专家（MoE）现在是主流架构，用稀疏激活把"参数量"和"推理成本"解耦。结果就是模型参数越做越大（有开源模型到 3 万亿参数），但单次推理只激活一小部分。

这带来一个统计上的麻烦：参数量不再能直接比较能力。看到"3 万亿参数"不用太激动，关键看激活参数和实际效果。

上下文和记忆

上下文窗口从 128K 涨到百万级，但"能塞进去"和"能用好"是两回事。长上下文里的信息遗忘、位置偏差、成本上升，都是问题。

2026 年更实用的方向是"记忆"：把用户和企业的长期信息存在外部，按需检索，而不是每次都塞进 prompt。这既是技术问题，也是产品问题——谁掌握了用户的长期上下文，谁就有粘性。

Agent 是 2026 年的主线，也是最难落地的

Agent 的逻辑很顺：模型不只是回答问题，而是替你完成任务——查资料、写代码、操作软件、跑流程。

但落地难点在可靠性。一个任务 20 步，每步 95% 正确，整体成功率只有 36%。企业要的是"99% 以上、出错可追溯"，现在的 Agent 还差得远。所以 2026 年真正跑起来的是"窄 Agent"：编程、客服、数据查询，任务边界清楚、有人兜底。

数据墙与合成数据

公开文本数据接近用尽，这是行业共识。接下来的数据来源：合成数据、企业私有数据、多模态数据（视频、语音）、交互数据（Agent 执行轨迹）。

合成数据的风险是"模型训模型"导致退化，以及评测污染。企业私有数据是真正的护城河，但拿不到、洗不干净、涉及合规。

开源和闭源的差距在缩小

开源权重模型（DeepSeek、Qwen、Kimi、MiniMax、Llama）在多数通用任务上已经接近前沿闭源，差距主要体现在最难的推理和多模态上。开源的好处是便宜、可私有化、可微调；坏处是没人对结果负责。

这个格局对闭源厂商是压力：如果开源模型"够用"，企业为什么要为前沿模型付 30 倍价钱？答案只能是"在最难的任务上明显更好"，或者"有别人没有的分发和集成"。

评测已经失真

榜单越来越不可信：训练数据污染、针对性优化、评测集泄漏。企业采购时更看重自己的私有评测集，而不是公开榜单。这也是为什么"榜单第一"越来越难转化成收入。

六、政策

监管这块，中欧走了两条完全不同的路：欧盟"先立总法、风险分级、管到模型层"，中国"管服务、管标识、备案制"。

2025.09 中国《AI 生成合成内容标识办法》 显式+隐式双标识，平台和应用商店都有义务
2026.05 中国《智能体规范应用与创新发展实施意见》 网信办、发改委、工信部联合，分类分级治理
2026.07 世界人工智能合作组织（WAICO）在上海成立 29 个创始成员
2026.08 欧盟对通用模型执法权启用 可对模型提供者罚款

欧盟原定 2026 年 8 月适用的一些高风险条款被推迟：招聘、教育、执法、移民相关的高风险系统延到 2027 年 12 月，嵌入医疗器械和机械的延到 2028 年 8 月。所以 2026 年 8 月打开的是"模型层"的门，不是全部。

对出海企业来说，真正的成本不在"要不要合规"，而在"从一套标准迁移到另一套标准"。内容标识这类能力，中国企业已经练过一轮；要补的是模型层的系统性风险评估、重大安全事件报告、技术文档留存。

国内备案也在常态化。广东一省累计备案就到 193 款，垂直行业模型（法律、物业、家电、快消、具身智能）都进了备案轨道，"不是通用大模型所以不用备案"这个想法已经不成立了。

七、商业模式

四种收费方式

模式 怎么收钱 毛利 现状
API 按 token 用多少收多少 20%–50% 主流，但价格战最狠
订阅 按月/按席位 60%–80% C 端和编程工具主流
私有化部署 一次性授权+年费 50%–70% 金融、政务、大型企业
云捆绑/广告 不直接收 AI 的钱 — 大厂常用，难单独估值

还有第五种正在出现：按任务或按结果收费。企业客户越来越不想为"token"付费，而想为"解决了一个工单""写完一个模块"付费。这个转变对应用层有利，对模型层不利——因为它把模型变成了原材料。

两把尺子：毛利和公司盈利

模型公司的毛利看着不错，但算上训练和资本开支，多数还在亏。Anthropic 上半年收入 162.86 亿美元、算力支出近 90 亿美元，还要承担几百人的研究员薪酬和未来 5,180 亿美元的算力承诺；OpenAI 的资本开支同样巨大。

所以判断一家模型公司，我一般看三个数：收入增速、算力成本占收入比、续约率。前两个决定它能不能规模化成生意，第三个决定收入是不是真的。

哪些场景算清账了

场景 能不能算清 备注
编程 能 按席位付费，替代外包和加班，ROI 直接
客服 能 替代人工，按工单量算
文档处理/合同 能 人力密集，错误可抽检
知识库 半能 项目制多，难量化
营销内容 半能 便宜，但效果难归因
通用 Agent 还不能 可靠性不够，责任不清
消费级聊天 不能 靠订阅和广告，ARPU 低

这也是为什么编程成了第一个爆发场景：任务边界清楚、结果可验证、替代成本高。Claude Code 从 3% 到 39% 的使用率，基本就是这个逻辑。

什么才算真拐点

我一般看四条：

  • 企业续约率稳定在 90% 以上，而不是靠新签撑增长。
  • 算力成本占收入比降到 30% 以下，说明规模效应出来了。
  • Agent 的端到端成功率到 95% 以上，且有可追溯的兜底。
  • 应用层出现年收入 10 亿美元以上的非编程品类，说明不止一个场景跑通。

现在第一条在头部公司可能接近，第二条还差得远，第三条、第四条都还在早期。

八、真正卡住行业的是什么

瓶颈 具体表现 影响
资本开支回报 3,000 亿美元级别的基建投入，推理收入能否覆盖存疑 最大
单位经济性 价格战 + 推理成本 + 训练成本，模型层难盈利 最大
可靠性与责任 Agent 出错谁负责，企业不敢托管关键流程 大
数据 公开数据用尽，私有数据难拿，合成数据有退化风险 大
分发 没有入口的模型公司，获客成本越来越高 大
电力与场地 数据中心依赖天然气，电力和合适场地竞争激烈 中偏大
监管 欧盟模型层义务、中国备案，出海合规成本上升 中

我的判断是：卡住这个行业的不是"模型不够聪明"，而是"算力投入和商业回报之间还没有闭合"。技术问题可以用更多算力和数据解决，经济问题不行。

产能上还有个容易忽略的点：数据中心的建设周期是 2–3 年。2026 年投的钱，要到 2028 年才能真正形成供给。这中间如果需求增速放缓，就会出现阶段性过剩——到那时候，价格战会更凶。

从市场结构看，模型层在通缩（价格战、商品化），应用层在扩张（成本下降、场景增加）。这和自动驾驶、具身智能是同一个规律：中间层被挤压，两端赚钱。

九、格局可能会怎么变

我大致这么看 2028 年：

环节 现在 2028 年左右
前沿闭源模型 OpenAI、Anthropic、Google 三强 3–4 家，可能有一家掉队
开源权重 中国厂商主导调用量 2–3 个主流基座，其余做微调
AI 芯片 英伟达主导 英伟达 + 1–2 家自研 ASIC 分走三成
云 三家 + 中国三家 格局稳定，AI 成为主要增量
编程工具 Cursor、Claude Code、Copilot 2–3 家，可能被平台吞并
企业应用 Microsoft 领先 平台 + 垂直并存
通用 Agent 创业公司混战 大部分被平台吸收

两个变量值得留意：

一是大厂的分发优势。 Google 有搜索、安卓、Workspace，Microsoft 有 Office 和 Azure，Meta 有 30 亿人的社交。模型能力趋同后，这些入口会变成决定性优势。纯模型公司要么做出现象级产品（比如编程工具），要么被收购。

二是开源。 如果开源模型在 90% 的任务上都"够用"，闭源厂商的定价权会被持续压缩，只能守最难的 10%。这 10% 很值钱，但撑不起现在的估值。

历史经验还是那句：技术换代时，领先者不一定活得久。2023 年的一线模型公司，到 2026 年已经换过一轮座次；2028 年大概还会再换一次。

十、机会和空间

把"故事多大"和"钱多确定"分开看，我的排序大概是：

  1. 应用层（编程、客服、垂直流程）
  2. 算力与基础设施（芯片、云、电力）
  3. 中间层（推理服务、路由、评测、安全）
  4. 开源生态与国产替代
  5. 前沿基础模型

这个排序和热度几乎相反：最热的是基础模型，最确定的是应用。

空间上，我自己搭了个粗略模型（单位：亿美元，只算模型层+应用层，不含硬件）：

部分 2026E 2028 悲观 2028 基准 2028 乐观
模型层收入（订阅+API） 830 1,100 1,600 2,200
企业应用（含 Agent） 350 600 1,000 1,500
中间层（推理/工具） 80 150 280 450
合计 1,260 1,850 2,880 4,150

分歧主要在两处：一是 token 价格继续跌，收入会不会被"量增价跌"抵消；二是企业 ROI 能不能在 2027 年续约季之前被证明。我对第二个更没把握。

如果按仓位想一下（只是框架示意，不是建议）：应用层可以分散配置，挑有真实续约和毛利的；算力层确定性高但要看估值和周期位置；模型层更适合小仓位、押注少数几家，因为赢家通吃、输家归零。

我会盯的几个数

  • token 用量增速 vs 美元收入增速：两者背离越大，说明价格战越凶。
  • 企业续约率：2026 年底到 2027 年是集中续约期，这是最硬的验证。
  • 算力成本占收入比：从 50% 往 30% 降，才算规模效应。
  • 编程之外的第二增长场景：客服之后，下一个是什么。
  • 开源与闭源的价差：价差缩小，闭源溢价就守不住。
  • 推理占算力支出的比例：从 55%–70% 继续上升，说明应用真的在用。
