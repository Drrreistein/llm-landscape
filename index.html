口径：仅含基础模型、推理框架与中间层、应用厂商。上游芯片、HBM、光模块、服务器与云基础设施不参与此视图——同一张 GPU 既跑训练也跑推理，按模型层级归类会失真。一家企业可横跨多列，取决于其产品线覆盖。

口径：仅含基础模型、推理框架与中间层、应用厂商。算力与硬件企业不按场景归类——同一颗芯片同时服务编程、客服与科研。一家企业可覆盖多个场景，标记数字即为其跨环节数量。

口径：行是玩家模式（卖什么、怎么收费），列是模型层级。拆五列不是按参数量，是按商业形态：前沿闭源卖 API 与订阅，开源权重卖生态与私有化，垂直专用卖结果，端侧小模型卖设备，推理/多模态卖能力溢价。硬件与基础设施不参与模式矩阵，理由见页脚。

两个值得注意的空格：模型厂商 × 端侧小模型基本由开源阵营占据（闭源前沿厂商很少单独做端侧）；应用厂商 × 前沿闭源高度密集，说明应用层目前仍高度依赖少数几家 API，切换成本与议价权都不在自己手里。
